# eScouter
<img width="981" height="500" alt="image" src="https://github.com/user-attachments/assets/65bf51a4-31c3-4b74-af82-65b8d993d104" />


Aplicativo que conecta **atletas** e **clubes/olheiros**

## Funcionalidades

-Cadastro de Usuários(Clube e atletas)
-Login e Segurança: 
-Inscrever-se/Cancelar inscrição em uma peneira
-Criar peneiras
-Editar/Excluir peneiras
-Editar/Excluir perfil
-Filtrar clube/atletas
-Cadastro de partidas


## Tecnologias
- Kotlin + Android Studio
- Firebase Authentication e Cloud Firestore
- Cloudinary ( para o upload de mídias)
- Retrofit ( API do IBGE)
- Coil e Media3 ExoPlayer

## Como rodar
1. Clone o repositório:
   ```bash
   https://github.com/Joao-Guilherme-GOliveira/eScouter.git
   ```
2. Abra a pasta no Android Studio
3. Altere o 'google-services.json' para o seus dados do firebase
4. Rode no emulador ou no seu próprio celular android
